# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计和污染事件联动处置。

## 污染事件联动处置

- **登记事件**：选择多张切片，填写污染原因、处置工序和登记人；事件开放后关联切片立即冻结，不能推进工序，所在批次拒绝交付并列出影响范围。
- **幂等登记**：事件编号重复提交只生效一次；同一切片不能同时处于两个开放事件。
- **解除事件**：解除人不能与登记人相同，须填写解除依据，并选择「续作」或「退回指定工序」。退回即返工，目标工序必须早于每张关联切片各自的当前工序（同工序、向前工序、未知工序均拒绝，事件保持开放且状态与记录不变）；并发解除仅一次生效。
- **页面展示**：事件列表、冻结切片标记、登记人/解除人签核信息，以及开放事件与冻结切片统计。

全流程验证（登记、冻结、续作、返工、重复提交、并发解除）：

```bash
node verify.mjs          # 输出运行标识 RUN
# 重启服务后校验数据保留：
node verify.mjs check <RUN>
```
